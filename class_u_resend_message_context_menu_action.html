Detailed Description

Message action which sends a moderation-bounced message again, unchanged.

Added to the action list in C++ rather than configured in WBP_ContextMenu, which predates moderation bounces.

Only offered on the author's own bounced message. Sending the same text again will usually be bounced again, so this sits alongside Edit rather than replacing it.
